# Drawing with CSS

Uma coleção de ilustrações criadas exclusivamente com **HTML** e **CSS**, sem o uso de imagens ou SVGs. O projeto reúne diferentes exercícios de CSS Art, explorando posicionamento, formas, animações e efeitos visuais por meio de propriedades nativas do CSS.

## ✨ Demonstração

https://anaclrsnts.github.io/projeto_drawing_with_css/

## 🎨 Artes disponíveis

* 🐢 Tortoise
* 🛰️ Satellite
* 🦜 Parrot
* 🐉 Dragon
* 🍦 Ice Cream
* ⚽ Bouncing Ball

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 📌 Conceitos praticados

* CSS Art
* Posicionamento com `position`
* Flexbox
* CSS Grid
* Pseudo-elementos
* Bordas e `border-radius`
* Transformações (`transform`)
* Animações com `@keyframes`
* Responsividade com Media Queries

## 📚 Objetivos do projeto

Este projeto foi desenvolvido para praticar técnicas de **CSS Art**, criando ilustrações apenas com HTML e CSS. Cada desenho foi construído como um exercício independente, explorando diferentes abordagens para composição visual, organização de estilos e animações.
